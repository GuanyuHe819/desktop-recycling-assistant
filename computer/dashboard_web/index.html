      Setup guide

      1. Join the 2.4 GHz hotspot

        Connect the computer and Arduino to the same phone hotspot. On iPhone, enable Maximize Compatibility.

      2. Open the dashboard

        Double-click 3_启动课堂Dashboard.bat and keep the launcher window open. If the hotspot details or the computer’s IPv4 address changed, re-upload the existing sketch through Arduino IDE.

      3. Choose a recognition model

        To add a Teachable Machine Keras export, put keras_model.h5 and labels.txt together in a new folder under models/. Select it before starting a session.

      4. Start sorting

        When the camera is live, MQTT is connected and Arduino says Ready, select Start sorting. Hold the camera on an empty scene first, then show one item.

      5. Wait for the green light

        Bring the item or your hand within about 10 cm of the lit bin’s sensor. After the result appears, clear the camera and the bins before the next item.

      End session lets the current drop finish. Refreshing keeps the session. Starting a new session or restarting the dashboard resets the totals and preserves the CSV log.

      A match means the sensor that fired was in the recommended bin. The camera model predicts the material.
